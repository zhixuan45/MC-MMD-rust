# 同目录 PMX 切换与独立手持 PMX 道具

## 模型设置

仍以 `EntityPlayer/<模型文件夹>/` 为一名角色，允许该文件夹内包含多个 PMX：

- **角色 PMX 文件**：决定人物本体使用哪个 PMX；“自动选择”继续使用默认扫描方式。
- **持物 PMX（主手）**：选择一个**仅包含道具几何体**的 PMX；“关闭”表示继续渲染原版物品。主手有物品时，人物本体保持不变，道具 PMX 附着到当前角色的右手骨骼矩阵。副手继续走原有渲染路径。
- 点击 **保存** 即可生效，无需改变当前角色选择。

持物 PMX 在模型仓库内单独异步加载（与人物 PMX 使用独立缓存键）。如果该文件不存在、无法加载、尚未加载完成或渲染抛出异常，原版主手物品照常显示。第一人称 TaCZ 枪械仍优先使用 TaCZ 自己的绘制与瞄准逻辑。

**请使用单独制作的 PMX 道具文件，而非包含整个角色的“持物角色 PMX”**；后者会把完整人物叠加在手上。

## 道具大小与附着变换

在模型设置中选择「主手道具 PMX」后，向下滚动到「道具朝向与握持位置」，即可调整 X/Y/Z 旋转、X/Y/Z 偏移与道具独立缩放。拖动滑条快速调整，点击两侧的 `-` / `+` 按钮微调（角度每次 1°，偏移每次 0.1，缩放每次 0.01）。点击「保存」后生效。

「重置道具变换」仅恢复道具的朝向、偏移与独立缩放，保留已选 PMX 和其他模型设置。现有「物品缩放」仍参与 PMX 道具缩放。

参数仍保存到 `config/mmdskin/model_configs/<角色文件夹>.json`，兼容原有配置（路径以实际模组配置目录为准）：

```json
{
  "heldPmxFile": "团扇.pmx",
  "heldPmxScale": 1.0,
  "heldPmxOffsetX": 0.0,
  "heldPmxOffsetY": 0.0,
  "heldPmxOffsetZ": 0.0,
  "heldPmxRotX": 0.0,
  "heldPmxRotY": 0.0,
  "heldPmxRotZ": 0.0
}
```

位移在主手局部坐标系，旋转单位为角度，默认均为 0；旋转按照 X、Y、Z 顺序组合，随手部动作一起运动。不同 PMX 的原始坐标轴可能不同，可先逐轴调整 90° 确认朝向，再微调握持位置。

## 自定义手形

在角色文件夹或其 `anims/` 子目录中放置手形 VMD，进入「模型设置 → 动作配置」，为「主手持物手形」槽位选择该文件并保存。建议 VMD 只包含右手手指骨骼关键帧；如需调整手腕，也可包含右手腕，但避免带入全身骨骼以免覆盖行走动作。静态握姿可使用只有一帧的 VMD。

该手形仅在已开启主手 PMX 替换、主手非空且没有使用物品、挥动、受伤或睡眠时循环叠加；使用和挥动结束后自动恢复。TaCZ 持枪动作、舞台和自定义全身动作继续优先。未选择手形或 VMD 加载失败时沿用现有动作。清除该槽位即可关闭自定义手形。

## 边界

- 只允许加载同文件夹内的普通 `.pmx` 文件；禁止路径穿越或符号链接。
- 此配置仅由当前客户端保存，未额外新增多人联机配置同步数据包。
- 默认主手检测为是否持有任意非空 Minecraft 物品；尚不支持针对单个物品 ID 为不同 PMX 分别配置替换。
- 使用 GPU、CPU、光影和第一人称时共享既有模型后端，但仍需进行游戏内兼容性测试。
