# 同目录 PMX 切换与独立手持 PMX 道具

## 模型设置

仍以 `EntityPlayer/<模型文件夹>/` 为一名角色，允许该文件夹内包含多个 PMX：

- **角色 PMX 文件**：决定人物本体使用哪个 PMX；“自动选择”继续使用默认扫描方式。
- **持物 PMX（主手）**：选择一个**仅包含道具几何体**的 PMX；“关闭”表示继续渲染原版物品。主手有物品时，人物本体保持不变，道具 PMX 默认附着到当前角色的主手矩阵，也可在「道具设置」中选择其他绑定骨骼。副手继续走原有渲染路径。
- 点击 **保存** 即可生效，无需改变当前角色选择。

持物 PMX 在模型仓库内单独异步加载（与人物 PMX 使用独立缓存键）。如果该文件不存在、无法加载、尚未加载完成或渲染抛出异常，原版主手物品照常显示。第一人称 TaCZ 枪械仍优先使用 TaCZ 自己的绘制与瞄准逻辑。

**请使用单独制作的 PMX 道具文件，而非包含整个角色的“持物角色 PMX”**；后者会把完整人物叠加在手上。

## 道具大小与附着变换

在模型设置中选择「主手道具 PMX」后，向下滚动到「道具朝向与握持位置」，即可调整 X/Y/Z 旋转、X/Y/Z 偏移与道具独立缩放。拖动滑条快速调整，点击两侧的 `-` / `+` 按钮微调（角度每次 1°，偏移每次 0.1，缩放每次 0.01）。点击「保存」后生效。

「重置道具变换」仅恢复道具的朝向、偏移与独立缩放，保留已选 PMX 和其他模型设置。现有「物品缩放」仍参与 PMX 道具缩放。

参数仍保存到 `config/mmdskin/model_configs/<角色文件夹>.json`，兼容原有配置（路径以实际模组配置目录为准）：

```json
{
  "heldPmxFile": "团扇.pmx",
  "heldPmxScale": 1.0,
  "heldPmxOffsetX": 0.0,
  "heldPmxOffsetY": 0.0,
  "heldPmxOffsetZ": 0.0,
  "heldPmxRotX": 0.0,
  "heldPmxRotY": 0.0,
  "heldPmxRotZ": 0.0
}
```

位移在所选绑定骨骼的局部坐标系，旋转单位为角度，默认均为 0；旋转按照 X、Y、Z 顺序组合，随手部动作一起运动。不同 PMX 的原始坐标轴可能不同，可先逐轴调整 90° 确认朝向，再微调握持位置。

## 自选绑定骨骼

进入「模型设置 → 道具设置 → 绑定」，可搜索当前已加载角色的骨骼，或手动输入精确骨骼名。选择「默认主手」恢复旧行为。绑定读取角色完成动画、IK 和物理求值后的骨骼全局变换，原有偏移、旋转和缩放在该骨骼局部坐标中继续生效。

选择后回到模型设置点击「保存」。模型尚未加载时仍可手动输入；实际模型缺少该骨骼时回退主手。重名骨骼遵循引擎既有的名称查找规则。更换本体 PMX 后会在新模型中重新查找，不沿用旧模型索引。

绑定位置与显示条件分开：即使绑定到头部，仍在主手持有非空 Minecraft 物品时才显示；此设置不会自动变成空手常驻配饰。

## 道具独立舞台 VMD

把只驱动道具自身骨骼/Morph 的 VMD 放入该角色文件夹或其 `anims/` 子目录，在「模型设置 → 道具设置 → 道具 VMD」中选择文件并保存。未选择时不加载独立 VMD，道具仍可使用自身物理。文件同名时优先读取 `anims/`。

道具实例关闭角色的自动眨眼和视线追踪，避免覆盖 VMD 中编写的相关 Morph/骨骼。

开播时保存当前道具 PMX 与专用 VMD 的选择。道具使用独立动画句柄，跟随角色所在舞台的同一个帧；不会覆盖本体动画或改变舞台结束依据。短动作到末帧后保持，默认不循环；长动作随舞台结束。道具异步加载完成时直接定位到当前舞台帧。

VMD 中的根骨骼运动在道具模型自身坐标内求值，再叠加外部绑定骨骼和局部变换。为其他坐标原点制作的动作可能需要重新调整资产，避免重复叠加位移。

停止、重播、断线及模型被释放时，会解除道具动画绑定并释放临时 VMD。缺失或加载失败的道具 VMD 回退到无独立 VMD 的道具，并记录日志；同一次绑定失败不会在每次绘制时重新加载。修改舞台 VMD 选择后应重新开播。

舞台广播会携带各玩家独立的道具 PMX 与 VMD 文件名。观看端需在其解析出的角色目录中拥有同名资源；文件内容不会通过网络传输。绑定骨骼、偏移、缩放和物理选项仍使用观看端的本地模型设置。旧数据包没有该字段时沿用无独立道具 VMD 的行为；要同步此功能，各客户端与服务端应更新到本次版本。

新增配置字段示例：

```json
{
  "heldPmxFile": "团扇.pmx",
  "heldPmxBone": "左手首",
  "heldPmxStageMotion": "团扇动作.vmd",
  "heldPmxPhysicsEnabled": true
}
```

清空 `heldPmxBone` 可回到默认主手；清空 `heldPmxStageMotion` 可关闭独立道具动作。两项可以分别关闭。

## 自定义手形

在角色文件夹或其 `anims/` 子目录中放置手形 VMD，进入「模型设置 → 动作配置」，为「主手持物手形」槽位选择该文件并保存。建议 VMD 只包含右手手指骨骼关键帧；如需调整手腕，也可包含右手腕，但避免带入全身骨骼以免覆盖行走动作。静态握姿可使用只有一帧的 VMD。

该手形仅在已开启主手 PMX 替换、主手非空且没有使用物品、挥动、受伤或睡眠时循环叠加；使用和挥动结束后自动恢复。TaCZ 持枪动作、舞台和自定义全身动作继续优先。未选择手形或 VMD 加载失败时沿用现有动作。清除该槽位即可关闭自定义手形。

## 边界

- 只允许加载同文件夹内的普通 `.pmx` 文件；禁止路径穿越或符号链接。
- 模型配置在当前客户端保存；舞台播放通过现有消息中的可选字段同步道具 PMX/VMD 文件名。
- 默认主手检测为是否持有任意非空 Minecraft 物品；尚不支持针对单个物品 ID 为不同 PMX 分别配置替换。
- 使用 GPU、CPU、光影和第一人称时共享既有模型后端，但仍需进行游戏内兼容性测试。
