# 同目录 PMX 切换与持物模型

模型文件仍以 `EntityPlayer/<模型文件夹>/` 为单位识别。一个目录可以放入多个 PMX 文件，纹理与动画仍从原模型目录读取。

1. 进入 **模型选择 → 模型设置**。
2. 在 **角色 PMX 文件** 中选择使用的 PMX（默认“自动选择”，继续使用原本的 `model.pmx` 或扫描排序首项）。
3. 可选：在 **持物 PMX（主手）** 中选择一个已经包含角色与主手道具的**完整角色 PMX**。当玩家主手非空时，会切换为这个 PMX，且不再重复绘制 Minecraft 主手物品。副手物品保持原版绘制。
4. 点击 **保存** 生效。使用“关闭”可恢复原版物品绘制。

注意：持物 PMX **不是独立道具网格**，而是拥有角色与道具的完整 PMX 变体，骨骼与动画应与默认角色相容。模型的默认形态与持物形态分开缓存。切换手持物品时，新形态首次加载可能出现短暂延迟；缺失文件会回退到普通形态与原版物品。设置为客户端本地配置，并未增加网络同步协议。

为了避免目录穿越，只允许选择所选模型文件夹内的普通 `.pmx` 文件，不接受目录路径、符号链接、其他扩展名。
