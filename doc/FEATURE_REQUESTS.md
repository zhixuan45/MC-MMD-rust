# 新功能申请 / Feature requests

简体中文 · [English](#english) · [返回 README](../README.md)

1. 先搜索 [GitHub Issues](https://github.com/zhixuan45/MC-MMD-rust/issues)，已有同类申请时，可以在原帖补充你的使用场景。
2. [打开功能申请表单](https://github.com/zhixuan45/MC-MMD-rust/issues/new?template=feature-request.yml)，用中文或英文说明你遇到的问题、希望在游戏里实现的行为，以及目标 Minecraft 版本和加载器。截图、视频和参考链接可按需附上。
3. 如果申请适配其他模组，请附上对方的项目链接、版本，并说明需要互通的具体功能。这个 fork 的内部 Java 接口与上游有差异。CNPCMmdSkin 当前不受支持，相关讨论见 [#25](https://github.com/zhixuan45/MC-MMD-rust/issues/25)。

如果是本项目已有功能出错，请通过 [GitHub Issues](https://github.com/zhixuan45/MC-MMD-rust/issues) 报告，并附上复现步骤、[构建信息](VERSIONS.md)和相关日志。

### 赞助开发

如果希望某项功能优先开发或加快进度，可以在申请表单中勾选赞助意向。已有申请也可以在对应 Issue 中说明。维护者会根据功能范围和可用时间讨论具体安排，排期以双方确认的内容为准。普通功能申请照常受理。

## English

[简体中文](#新功能申请--feature-requests) · [Back to the English README](../README.en.md)

1. Search [GitHub Issues](https://github.com/zhixuan45/MC-MMD-rust/issues) first. If someone has already requested the same feature, add your use case to that issue.
2. [Open the feature request form](https://github.com/zhixuan45/MC-MMD-rust/issues/new?template=feature-request.yml). In English or Chinese, describe what you are trying to do, what you want to happen in game, and which Minecraft version and loader you use. Add screenshots, videos, or reference links if they help.
3. For a mod integration, include the other mod's project link and version and describe what should work together. This fork's internal Java interfaces differ from upstream MmdSkin's. CNPCMmdSkin is currently unsupported. See [#25](https://github.com/zhixuan45/MC-MMD-rust/issues/25).

If an existing feature in this fork is broken, report it in [GitHub Issues](https://github.com/zhixuan45/MC-MMD-rust/issues) with reproduction steps, [build details](VERSIONS.md#english), and relevant logs.

### Sponsoring development

If you would like to help prioritize or speed up development of a feature, indicate your interest in the request form or comment on its existing issue. The maintainer can discuss the scope and schedule based on availability. Any schedule is agreed separately. You can also submit a regular feature request.
