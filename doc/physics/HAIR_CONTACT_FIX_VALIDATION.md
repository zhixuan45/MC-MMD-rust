# 头发与饰品物理检查记录

2026-10-15 最新澄清：用户确认 S 形是模型本身表现，参考图中的肩侧碰撞正常；异常是蝴蝶结抖动，仅在游戏中出现，TransformView 中没有。撤回“肩部持续支撑即异常”的判断，停止推进身体网格接触替换提案。以下接触实验保留为调查记录，不作为修改正常 S 形或减少肩部冲量的理由。蝴蝶结尚未修复或完成游戏验收。

左右蝴蝶结的作者数据：动态刚体 #467/#468，骨骼 #575/#576，质量 0.2、线性/旋转阻尼 0.999、允许碰撞掩码 0。关节 #712/#713 分别连接长发首节 #280/#286，局部 Y 平移 0～0.3，旋转 X/Y/Z 分别 ±15°/±10°/±30°，无弹簧。原始无碰撞资格不能证明运行中所有规则均未改变，也不能把抖动直接归因于蝴蝶结撞肩；需联合有效规则和接触核对。

完整运行探针增加可选 `--watch-body <名称片段>` 的只读逐帧观察，记录匹配饰品和关节另一端的模拟、MotionState、骨骼重建及相对姿态，配合越界量、锚点误差、角速度和 CPU 代表点，先区分真实模拟与显示抖动。未采中间子步和未验证游戏 GPU 路径的边界保持明确。新检查计划见 `plans/hair-physics/side_contact_implementation_plan.md`。

新增饰品取证已运行待机、侧转保持、横向移动和独立摆臂各 60/144 FPS，共 8 条件，使用原开发配置，未启用几何或旧关节对照。`bow-trace/authored-60.jsonl` 与 `authored-144.jsonl` 分别保存 5493/13137 行，汇总为 `bow-trace/summary.json`。此次保持和停止阶段为 5 秒，不能冒充 30 秒长期静置验收。左右长发蝴蝶结在采样的最后子步均未记录到直接接触，且目标和点未截断；不代表已观测所有中间子步。

正向侧转保持的最后两秒，右蝴蝶结关节 Y 角峰峰值约 20.03°/31.05°，角限位越界向量最大长度约 2.75°/7.65°（60/144 FPS）。这些是限位坐标下的变化，需结合连续姿态判断自然摆动与异常抖动，不能只用幅度定义故障。八条件中，左右长发蝴蝶结由最终骨骼重建的刚体矩阵与 MotionState 矩阵最大分量差约 3.82e-6，支持先调查模拟关节及父发节输入，而不是先修改 CPU 骨骼回写；此结论不覆盖游戏 GPU 蒙皮或游戏特有的多次更新。尚未确认根因或修改生产物理。

逐帧取证入口：先 `cargo build --offline --release --manifest-path rust_engine/Cargo.toml --example probe_hair_runtime`，再给现有探针命令增加 `--watch-body 长发蝴蝶结 --sample-interval 0.001`，并显式指定 `--fps 60,144 --cases idle,head-side-hold,lateral-stop,arm-contact-stop --head-degrees 60`。此入口按渲染帧采样，不会增加模拟子步。未匹配名称会失败，样本同时标出匹配数。

第二轮侧摆调查已增加 `head-side-hold` 和 `lateral-stop`，同时记录接触对方的真实 shape/姿态，并提供可选 CPU 网格导出。左右转头、移动/摆臂及 60/144 FPS 分别对照，不能相互代替。探针 `--diagnostic-control` 只修改进程内模型副本，并在记录中标记参数已改变；自由轴和 0.7 肩半径均不是默认修复。原始 PMX、游戏配置和已交付 DLL 没有因这些实验改变。原接触替换提案已由最新蝴蝶结检查计划取代。

侧摆证据包含 16 个运行条件，记录中的错误和非有限数均为 0。左右侧转保持可采到首节被肩部支撑；60/144 FPS 正向侧转保持末时刻的向上法向冲量分别约 36.93/36.62，反向 60 FPS 约 42.43。即使将发根三个旋转轴全部设为自由，末时刻仍约 37.84。肩半径仅在探针内由 0.6 改为 0.42 时，保持末时刻的该肩部接触未采到；60 FPS 过渡阶段仍采到峰值约 4.37，不能说全程没有肩部接触。这些属于正常接触基线的取证，不证明需要消除该支撑。移动与转头仍须分别检查蝴蝶结抖动。

`Logs/hair-shoulder-20261015/side-turn/summary.json` 保存逐条件结果，数值为稀疏最后子步快照，不能当成所有子步峰值。`mesh-clearance.json` 和 `all-material-clearance.json` 保存同帧接触点到实际三角面的距离；该位置最近的身体表面 Skin 距离为 0.2068，头发面为 0.01985。肩部实际姿态与其骨骼绑定映射一致，不能将这份证据归因为已确认的坐标偏移。网格导出和间隔图仅作离线诊断，不是游戏验收。

用户观察到杏辞模型长发靠近手臂后被推开，停止等待仍保持弯曲和浮空。最初按外部 Minecraft 实例配置检查肩部，随后用户明确是在开发环境测试且未改物理配置。实际开发配置为 STABLE、60Hz、最大 5 子步、重力 -98、速度限幅 20、惯性 1、自动上下身体壳开启、静态碰撞体倍率 1.0、运动学滤波关闭。配置文件没有修改。开发日志确认用户此前加载的本轮诊断 DLL 为 `92d893959741a8d4dcc024ce6d44646c561f09b7019fee715a9eb44692876785`，当时几何策略默认关闭，不能把该次画面测试称为有效修复验收。

## 默认候选修正

`mmd_joint.rs` 默认保留作者头发关节的限位和弹簧，继续执行既有通用非法值处理。不再因名称命中后发而自动添加只准向外的单向根限位，也不自动把无旋转弹簧的发根、子链改成 20°/14°限位与回正弹簧。该行为同时适用于模式 1、模式 2，不依赖模型名称或固定刚体索引。模型质量、阻尼、碰撞形状、掩码、身体壳和原始 PMX 保持原有设置。正常身体、手臂、袖子碰撞仍存在。

旧规则根据绑定姿态的质心方向推断“向内”，不能判断当前手臂和头发的相对位置。单向限位阻挡避让方向，子链额外限位和弹簧又限制下游转动。在手臂顶入时，两者可能和接触约束互相抵抗。完整运行对照已采到这一放大路径；用户截图幅度的视觉闭环仍需游戏复验。

开发对照入口为 `MMD_HAIR_JOINT_COMPAT=legacy`。`authored-root` 表示恢复作者根约束、保留旧子链兜底；`authored-chain` 反之。未设置、`authored` 或其他值均保留作者头发约束。只在世界创建时选择，不逐帧换约束，不写入用户配置。第一次加载、重置和重建都使用同一路径。

## 独立实验

`arm-contact-stop` 经生产 `MmdModel::tick_animation`、真实 idle VMD、VPD 骨骼覆盖、运动学目标同步、Bullet 求解、物理回写和 CPU 蒙皮运行。先待机 10 秒，再将左上臂围绕局部 X 轴后摆 60°，渐变 3 秒、保持 3 秒、回退 3 秒，清除覆盖后观察 30 秒。只驱动动画骨骼，未瞬移动态刚体。这个明确的探针输入用于区分机制，并非声称重放了用户的游戏操作。

最终同一 release 二进制的默认/legacy 对照补齐了每秒诊断窗口。针对左上臂 `#16` 与后长发 `#280～285` 的同点向上法向冲量，窗口记录峰值在 60 FPS 为旧 180.40、新 0.89，在 144 FPS 为旧 178.40、新 1.90。它们高于上述稀疏快照的峰值，说明只看截图时刻或低频瞬时快照会漏掉顶推。窗口仍只采每次 world step 的最后子步，不代表未采中间子步；目标没有发生截断。证据文件为 `arm-window-peaks-final.json` 和对应 JSONL。

绑定几何审计覆盖五种权重、所有正权边界、连通网格、镜像、手性和骨骼/刚体 offset。八份真实资产只在杏辞的两个最末端球体获得保守胶囊拟合资格，其余资产不改形状。拟合对上臂触发不够充分，继续保持实验关闭；开启需显式设置 `MMD_HAIR_COLLIDER_COMPAT=geometry`。不缩成统一半径，不修改原模型。

## 复验与游戏验收

直接重新启动开发客户端即可使用默认候选修正，不需要修改物理配置，也不需要开启几何实验。必须结束旧 Java 客户端进程后再启动，仅重新选模型无法替换已经加载的 DLL。新日志“原生库已加载”行的 SHA-256 应与上述值相同。若进程环境中曾设置 `MMD_HAIR_JOINT_COMPAT=legacy`，需要移除该对照变量。

离线复验示例，在仓库根目录执行：

```powershell
$pmx = 'C:\tmp\mc-mmd-rust\neoforge\run\client\3d-skin\EntityPlayer\TDA 方舟指令[洛天依][杏辞] Ver 1.00\TDA 方舟指令[洛天依][杏辞] Ver 1.00.pmx'
$cfg = 'neoforge/run/client/config/MmdSkin/config.json'
./tools/hair-physics/run-runtime-probe.ps1 -Model $pmx -PhysicsConfig $cfg -Variant legacy -Cases arm-contact-stop -Output Logs/hair-shoulder-20261015/repro-legacy.jsonl
./tools/hair-physics/run-runtime-probe.ps1 -Model $pmx -PhysicsConfig $cfg -Variant default -Cases arm-contact-stop -Output Logs/hair-shoulder-20261015/repro-default.jsonl
./tools/hair-physics/summarize-runtime.ps1 -Baseline Logs/hair-shoulder-20261015/repro-legacy.jsonl -Candidate Logs/hair-shoulder-20261015/repro-default.jsonl -Output Logs/hair-shoulder-20261015/repro-summary.json
```

同相机、模型、动作、光影和配置下，先待机 10 秒，分别转头、移动摆臂后停止观察左右蝴蝶结。正常 S 形和肩侧挤压是保留项，游戏中特有的异常抖动才是本轮验收目标。其它带物理饰品的模型、不同帧率及重置/重建仍需回归。离线构建、计数和数字轨迹均不代替游戏画面对照。

原始证据保存在 `Logs/hair-shoulder-20261015/`；该目录不纳入 Git，正式复验脚本在 `tools/hair-physics/`。本轮不自动提交或推送。
