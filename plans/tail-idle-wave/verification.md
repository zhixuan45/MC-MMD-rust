# teio-1 尾巴闲置波形实验

日期：2026-10-25。独立分支 codex/teio-idle-wave，基于 PR #22 提交 68e339d；不更新该 PR。

## 用户目标与范围

用户指定 teio-1 的真实尾巴，期望类似音频波形的起伏；每轮激活时间在 10–20 秒间独立随机取值。本实验按相邻尾根脉冲开始时间间隔定义该值。单轮受力采用 1.2–1.6 秒 sin² 平滑包络，保留重力回落，不额外强制骨骼沿理想正弦运动。

## 模型与修复

实际 PMX 为 teio-1/1003_Tokai Teio.pmx。目标刚体 #42–46：Sp_Hi_Tail0_B_00_physics 至 _04_physics，对应骨骼 #221–225；均为类型 1，质量 0.9/0.745/0.59/0.435/0.28。静态锚点和 blocker 不施加闲置力。没有把后长发分类为尾巴。

- 恢复上游后端的独立尾部闲置受力入口，强度采用历史首版 2 倍，而非旧参考实现额外放大的 8 倍。
- 复用已有尾链拓扑算法，恢复按长度归一化的逐节延迟，首尾 0.6 秒。保留循环父链、无效索引和多尾链处理，避免复制较弱的临时算法。
- 偏心施力先把刚体局部作用点转换为世界空间相对质心位置，再调用 Bullet applyForce；不重复施加中心力。
- 使用实际模型移动速度淡出闲置受力，重置或长帧恢复时清除波形历史。

- probe_tail_idle_wave 在 60 / 144 FPS 各跑静止、跑动后停止、重置三场景，每场景 80 秒。每帧用同时演算的闲置力关闭模型作为对照。五节尾骨均保持有限值。
- 静止时 60 FPS 触发时刻：10.10 / 26.416668 / 37.483334 / 54.700005 / 73.066673 秒；间隔 16.316668 / 11.066666 / 17.216671 / 18.366668 秒。144 FPS 与之相差不超过一帧。
- 受力延迟：0 / 0.105312 / 0.268731 / 0.454934 / 0.600000 秒。60 FPS 第一轮峰值时刻为 10.866667 / 10.983334 / 11.150001 / 11.333334 / 11.466667 秒。

- 第一轮尾尖相对关闭模型的后向位移 RMS，10.1–14 秒至 23–26 秒：60 FPS 为 0.18820→0.10426；144 FPS 为 0.15094→0.11926 PMX 单位。存在衰减，实际位移也包含关节/接触余振，并非理想平滑正弦。

## 约 1 PMX 上抬与 0.5 PMX 后移目标（2026-10-25 后续实验）

用户反馈旧包上抬不明显，要求目标上抬约 1 PMX、向角色后方约 0.5 PMX，允许在 1 PMX 上下随机变化，并保留 10–20 秒随机触发、逐节传播；不更新 PR。

直接提高同向附加力虽然可让首轮抬高 0.985 PMX，但会产生约 2.5 PMX 后摆；叠加旧随机力度后个别轮次抬高超过 2.5 PMX。该标定中间版本未安装。

最终实验改为仅在尾巴闲置包络内用中心附加力接近位移目标，目标幅度随机倍率为 0.9–1.1；普通惯性和刚体/关节/碰撞参数不变，不直接覆盖骨骼或刚体变换。各尾节共用本轮开始前的参考姿态并继续延迟传播，阻尼使用骨骼控制点速度（包含角速度影响）。单轮平滑包络延长至 2.4–2.8 秒，减少快速跟随过冲。移除不再使用的偏心施力接口。加速度限幅为 800 PMX 单位/秒²，并继续受已有全局速度上限控制。

60 FPS、80 秒静止演算五轮结果：抬高 0.897/1.100/0.920/1.127/1.242 PMX；在各轮抬起最高点同时后移 0.452/0.623/0.504/0.546/0.543 PMX。触发间隔仍为 16.32/11.05/17.22/18.37 秒。

144 FPS、80 秒静止演算五轮结果：抬高 0.950/1.112/0.983/1.221/1.080 PMX；各轮最高点同时后移 0.462/0.621/0.234/0.421/0.743 PMX。尾巴和关节继续参与物理，位移目标不是严格位置钳制，峰值时刻与回落余振存在波动。

60 FPS 的静止、跑动停止、重置三场景各 80 秒均保持五节尾骨矩阵有限。原始 CSV 位于 build/tail-idle-wave/height-1pmx/，final-60-all.csv 和 final-144.csv 是最终双向目标版本的帧率/场景对照；此前 gain、up4 和 target 中间标定文件仅作排除证据。

## 方块单位版本（2026-10-25）

用户提供 13.27 秒 / 30 FPS 录屏，要求将尾巴闲置目标统一改成方块单位。抽帧表位于 build/tail-idle-wave/block-units/video-contact-sheet.jpg：尾巴大部分时间下垂，约 8 秒处可见末端小幅外摆。代码核实 BaseModelInstance 的基础渲染比例为 0.09 方块/PMX 单位，teio-1 的 modelScale 为 1.0；旧目标 1 PMX 实际只有 0.09 方块。

Java 每帧通过新增的 SetTailPhysicsScale / NativeScenePort 接口传递 0.09×实际 modelScale；原生层按每模型保存该比例。尾巴目标（上方 1、后方 0.5）、参考位置、控制点速度、重力补偿及 72 方块/秒²的附加加速度上限均使用模型局部方块单位，只在 Bullet 边界将输出换回 PMX 加速度。缩放发生变化时清除旧尾巴反馈历史。普通世界移动坐标和惯性公式不参与此换算，保留前面修复，避免再次把惯性放大。

10–20 秒随机触发、0.9–1.1 目标幅度变化与 0.6 秒逐节传播保持。目标并非硬性位移覆盖；当前尾链的可达范围和关节继续限制实际姿态。

60 FPS、40 秒真实 teio-1 演算：三轮抬高 0.801/0.807/0.810 方块，最高点同时后移 0.361/0.362/0.357 方块；五节尾骨均保持有限值。数据为 block-units/blocks-60.csv，CSV 同目录 metadata.json 文件明确标注单位和实际缩放。129 项库测试通过、2 项忽略，3 项接入测试通过；新增测试覆盖不同渲染比例下的相同世界加速度、无效比例拒绝及世界惯性坐标不随模型大小被放大。
