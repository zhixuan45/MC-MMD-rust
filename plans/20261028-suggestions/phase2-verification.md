# 2026-10-29 第二批：骨骼挂接与独立道具 VMD

本批实现 R4、R5，保留第一批的 float32 音频、加载进度、VPD 姿势、结束帧策略与道具自身物理控制。用户已明确要求完成后直接推送主分支；仓库默认分支为 `feat/1.21.1-neoforge`。两批以独立提交保留，发布基线为 `2bcb2ee1342555eb523209ed4993f60ff1b304f2`。

## 使用

在模型设置的手持 PMX 区域选择道具、挂接骨骼和舞台动作，保存后生效。骨骼候选来自已加载的角色；模型未加载时可输入准确名称。空值或骨骼缺失时回退主手，仍沿用主手持有物品时显示的规则。读取的是求值后的骨骼全局矩阵，包含绑定位置，不使用蒙皮偏移矩阵。

道具 VMD 放在该角色目录或其 `anims` 子目录，同名时优先 `anims`。独立道具骨骼及 Morph 跟随统一舞台帧；短动作保持末帧，长动作随舞台停止，且不影响舞台结束帧。未选动作时保留道具自身物理行为。道具实例关闭角色自动眨眼与视线追踪，避免覆盖 VMD 关键帧。

舞台开始时固定本次道具 PMX/VMD 分配，迟加载的模型接入当前帧。退出、重播、换模型及断线时解除动画绑定并释放独立句柄。动作文件加载失败时保留静态道具，不按每次绘制反复加载。播放中修改动作选择须下次开播生效。

联机同步每位参与者自己的 PMX/VMD 文件名，参与者加入时不会误用主持人的道具分配。文件内容不经网络传输，各端须在对应角色目录准备同名资源；绑定骨骼、偏移和物理开关仍使用观看端本地配置。客户端与服务端建议一起更新。更多说明见 [PMX_VARIANTS.md](../../doc/PMX_VARIANTS.md)。

## 尚需验收

本次没有实际游戏客户端、配套 PMX/VMD 样本和原始 WAV，尚未做游戏画面、音频听感及真实多人联机验收。程序验证不代替这些检查。

R1 的角色与道具跨模型碰撞尚未实现；两者依然使用独立物理世界。本批未把道具自身物理开关当作跨模型碰撞功能。

本地预览 JAR 只包含 Linux x64 原生库，Java 与 native 须使用同一版本。Windows/macOS 需要同份源码的匹配平台构建；不得把预览包视为已完成 Windows 验收。
