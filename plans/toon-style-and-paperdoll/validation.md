# 光影二维化、描边与纸娃娃性能

2026-10-25。以 GPU 蒙皮为主要使用场景；此次也补齐 CPU 模型级并行。

## 可调效果

Fabric / NeoForge 的三渲二设置新增两个 0–100% 滑杆，两者默认均为 0，旧配置保持原样。

- **光影二维化强度**：缩窄明暗过渡，降低材质高光和边缘光，保留导数抗锯齿宽度、光影包照明、投影与环境色。建议从 60% 开始，再按实际画面调整。
- **光影球面反光抑制**：削弱 SPA / SPH 的加色或乘色效果，100% 时不再采样球面颜色。不会改变材质透明度或眼睛发光。

仅在包照明或 Iris 通用环境照明路径生效；GUI 和无光影保持原效果。CPU / GPU 蒙皮均调用同一个 `ToonRenderHelper`，并使用相同的主体与描边 shader。描边跟随光照时同步二维化色阶。

## 描边原因与修复

只读解析杏辞 PMX：40,181 顶点、57,009 三角形、40 个材质。全部材质均未设置 PMX `draw_flags & 0x10`。之前新增的子网格 offset 18 `hasEdge` 过滤会跳过全部材质，造成整个模型的三渲二描边消失。

恢复模型级外壳描边，仅按 offset 16 可见性和实际 alpha / 纹理裁切过滤；同步诊断采样规则。未关闭主体透明或物理。无边缘标志与有边缘标志材质的混合回归通过，旧过滤条件下该回归只访问 1/2 个可见子网格。

## 性能观测与改动

现有游戏日志 2026-10-25 16:48 的杏辞 GPU / BSL 窗口中，150 帧有 150 次 SHADOW 求值；WORLD 和 PAPERDOLL 都是 0 次求值、150 次复用。PAPERDOLL 物理求值为 0，因此该样本排除了纸娃娃重复物理。原生物理阶段平均约 4.736 ms，纸娃娃主体 CPU 提交平均约 0.608 ms、描边约 0.063 ms；这些 CPU 时间不能直接等同于 GPU 光栅时间。

呈现帧中位数 33.383 ms、P95 34.968 ms。配置为物理 60 Hz、最多 5 子步、solver 10 次迭代；未调整这些参数。当前移植物理路径缺少 Bullet 子阶段计数，不能将零步计数解释为没有物理步进。此窗口不是纸娃娃开关的固定条件 A/B，不能据此声称恢复了 10 FPS。

1. 纸娃娃原有 30 / 60 Hz 图像缓存不再一律排除 Iris：开启 Toon、双手为空且实际渲染目标通过检查时可缓存。GUI 使用自有 vanilla Toon 程序及独立深度，不加入世界透明队列；stencil、logic op、sRGB、MRT 等不兼容目标仍直接绘制。默认每帧模式没有改变。可用 `-Dmmdskin.paperDollIrisCache=false` 单独关闭本次 Iris 缓存放行。较高游戏帧率下可尝试 30 Hz 来减少纸娃娃刷新；60 Hz 在低于 60 FPS 时不会减少每帧刷新次数。
2. CPU 后端接通纸娃娃世界姿态复用：第三人称用完整身体索引，第一人称必须有独立裁剪 EBO。CPU 模型不再必然获取第二份纸娃娃实例并重复动画、物理。
3. CPU 后端接入现有世界 / 阴影的模型求值批次，后台仅运行独立句柄 JNI，等待全部完成后仍由渲染线程上传、绘制。多模型任务各使用内部预算 1，保留单模型已有 Rayon 顶点蒙皮，避免嵌套过度竞争。本地玩家、VR、TaCZ、舞台、外部姿态等保守回退继续有效。`-Dmmdskin.parallelEvaluation=false` 可做串行对照。

## 验证

- JDK 21 / Gradle 8.11.1，共享缓存与已有 daemon；定向 Java 回归 73 项全部通过，两平台编译、Fabric `remapJar`、NeoForge `shadowJar` 成功。
- 真实 BSL 8.4 / 10.1.8、Complementary 4.7.1 的 126 组程序 / 选项通过主程序、描边、输出和变体切换验证。Reimagined / Unbound 5.9.3 额外各 12 个真实程序通过编译。
- 新滑杆在真实 BSL / Complementary 光照下通过像素对照：平坦区、高光抑制、SPA / SPH、透明度及无光影隔离。
- 描边 GL 探针通过：模型级描边、纹理遮罩、纸娃娃宽度、异常和状态恢复。
- `BatchGlProbe`、`GpuPreparationGlProbe`（25 组 CPU/GPU oracle）、`PaperDollGlProbe` 通过。
- 杏辞真实 JNI：4 个独立句柄 CPU 并行与串行、单模型 Rayon 预算对照各 60 帧，骨骼 / CPU 顶点 / 法线最大绝对差均为 0。该探针不测游戏 FPS。
- 包内新配置界面、shader、三语文本、CPU 并行和 Iris 缓存代码已核查；两包的 Windows DLL 均与当前 release 输出逐字节一致。哈希与原始验证日志位于 `build/toon-style-validation/`。

扩展检查的 `AlphaOrderGlProbe` 未通过：4 条路径颜色相同，但相对其手动 oracle 有 2,236 个深度像素差异。将此次修改的两个 shader 替换为 HEAD 原版资源后同样失败；关闭深度剥离后也相同。它是当前基线的未决深度回归，不能宣称整个透明探针套件通过；本次未借机修改透明深度规则。

## 游戏内待验收

新包未替换到运行中的客户端。固定 GPU 蒙皮、杏辞、分辨率、动作、视角和同一光影包，对照两个风格滑杆的 0% / 60% / 100%，确认外轮廓、透明发片、眼睛和阴影。固定场景分别对照纸娃娃关闭、每帧、30 Hz、60 Hz，检查缓存 refresh / hit 与呈现帧 median / P95；再比较 CPU 并行开关。需要实际客户端画面和帧时间，才能确认最终二维感及掉帧改善幅度。
