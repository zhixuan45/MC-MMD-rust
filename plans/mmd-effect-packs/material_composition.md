# 按材质组合多个效果包

用户目标：同一角色的不同材质可选择不同包内的 FX，并自由组合。

- 配置新增角色/场景两份模型级绑定表，每条规则保存材质序号、原名称与效果 id。无规则继承整模默认，空效果明确关闭；精确规则优先于整模默认，也可在整模关闭时独立启用。
- 每个材质一次选择一个 FX，可跨导入包组合；暂不叠加同一材质的多个 FX。人物与场景隔离，世界设置维持独立。
- 模型绘制作用域收集默认效果与绑定引用，生成单个程序组合；颜色函数分别命名，避免不同包互相覆盖。普通绘制切换材质参数和纹理，不逐材质重编译。
- 透明排序保留全模型的三角形顺序。组合变体的批量材质行从 96 字节扩为 432 字节，追加七通道描述；原变体仍为 96 字节。额外贴图加入原纹理窗口，达到容量时按原三角形顺序拆窗口。GPU 排序/间接提交沿用原路径，单窗口容量不足时使用已有兼容路径，不按效果重新聚组。
- 作用域、shader 缓存、材质求值缓存、批次键、贴图引用和重载均考虑新绑定。批量表携带效果选择，无效果/颜色/Ray 材质可在同一提交中混合。
- 界面：效果包 → 材质组合 → 当前角色/已放置场景 → 实际 PMX 材质 → 任意已导入 FX / 继承 / 关闭；提供全部继承。
- 验证：配置兼容与绑定优先级、重名/改名材质防串绑、GLSL 330/430 组合、混合材质 CPU 逐 draw 与材质表像素等价、纹理窗口边界、透明顺序和 GPU 排序、GL 状态及现有回归。
