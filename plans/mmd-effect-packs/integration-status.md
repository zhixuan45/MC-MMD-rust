# FX 接入代码与待验证范围

## 本轮代码

- `.fxgraph.json` 可以随 ZIP 或目录导入，出现在效果列表，并选择为世界效果。每个节点引用现有 MME 颜色解析器支持的 FX；支持前序目标依赖、独立 RGBA16F 目标与最终世界输出。图不提供任意 HLSL、多输入、深度、控制器、历史帧或 MME Script 的自动转换。
- 世界渲染通过现有 HUD 前钩子执行图，OpenGL 后端复用节点 framebuffer，效果改变、尺寸变化、重载及关闭时释放。每个节点 shader 使用原有颜色转换器编译并缓存。
- 阴影使用原程序的克隆，包装绑定单元 0 的唯一 sampler2D 的两参数 texture/texture2D 采样，包含 Iris 包装入口后的辅助函数；保留采样的 RGB、原 UV 表达式及原 alpha-test，仅替换采样 alpha，再由包原有颜色和材质透明度运算处理。副作用限定在阴影作用域并恢复纹理和程序。
- 复杂纹理采样、非唯一主纹理或额外 shader 阶段等超出适配范围时保留宿主程序并报告，不宣称全部光影包兼容。实心阴影选项继续使用既有路径。

## 待统一验证

统一构建、Java 测试及 OpenGL 探针已经执行，结果和实机待验项见 validation-results.md。真实多 pass MME 素材仍需按其实际语义编写专用适配器，当前图入口为显式 manifest。
