# Ray-MMD 1.5.2 分阶段适配计划

日期：2026-11-01。输入为用户提供的 `ray-mmd-1.5.2.zip`。

## 基线与边界

- 268 个文件走 Ray 材质适配器，34 个参数解析通过，234 个失败；详见
  `build/ray-1.5.2-diagnosis-20261101/diagnosis.md`。
- 公共实现哈希与现有白名单一致。保留包内路径、源码大小和未知代码拒绝规则。
- 普通提交、批量提交、主体透明及阴影必须保留相同参数语义。
- 保留当前两个 renderer 的未提交改动及 shader-state-probe；只在必要的描边调用处
  增加材质名参数，不修改游戏实例。
- 导入成功、OpenGL 探针和实机画面分别记录；不把通过导入视为视觉等价。

## 阶段一：表达式与基础静态材质（已完成代码与自动验证）

1. 提取独立、有资源上限的常量表达式求值器：
   - 标量/向量、括号、一元正负、四则运算及标量广播。
   - 嵌套 float/half 构造器、pow、exp、saturate 等白名单纯函数。
   - 常量引用、有限的对象宏和函数式宏；拒绝未知运行时输入、循环和非有限结果。
   - 正确消费 static const 声明，保留未知代码检查。
2. 明确诊断 Editor 控制器依赖；不为 CONTROLOBJECT 静默填充常量。
3. 补齐 ALPHA_MAP_FROM=0、常量 alpha 和 ALBEDO_MAP_APPLY_DIFFUSE=0/1；
   在材质快照和 GLSL 中显式传递，不依赖修改原 FX。
4. 补齐 ALBEDO_SUB_ENABLE=4 的 Ray ColorSynthesis 混色；基础色常量、贴图解码、
   diffuse 乘色及混合在线性空间求值，再转换到宿主颜色接口。
5. 同步主体、描边、深度/透明候选和阴影采样包装，避免常量 alpha 仍被 PMX 纹理挖空。
6. 验收：表达式错误/边界测试、导入器真实包复扫、静态材质像素与批量路径探针、
   common 测试和加载器编译。记录通过数及剩余错误分类。

## 阶段二：时间、闪烁与 GIF（下一阶段，尚未实现）

1. 采用一致的单调时间源，对应 Ray TIME；同帧主体、深度和阴影不能推进不同帧。
2. 支持 EMISSIVE_MAP_APPLY_BLINK=1 的平滑三角波及三分量频率；
   =2 依赖 CONTROLOBJECT，保留明确诊断。
3. 实现受限 GIF 解码、帧间隔、透明/局部帧处置、循环和纹理更新；
   限制文件、尺寸、帧数、累计解码内存，并处理重载/关闭资源释放。
4. 支持动画贴图来源 2，保持普通及批量绘制一致；
   BodyLine 的颜色、UV 翻转、强度及闪烁不能丢失。
5. 验收：合成多帧 GIF 的时间/处置测试、真实 BodyLine 解码和固定时刻像素检查、
   切换/重载释放及批量路径检查。

## 阶段三：专用着色模型（待阶段二验收，尚未实现）

1. 扩展材质模型标识及 CUSTOM_A/CUSTOM_B 参数/纹理，统一普通和批量布局。
2. 分别实现并验证 Clear Coat=6、Skin=1、Anisotropy=3；
   每个模型完成后才开放其导入选项。
3. 清漆覆盖层处理第二层微表面、Fresnel 和能量分配。
4. 皮肤处理曲率、厚度、透射/散射；区分宿主局部实现与 Ray 屏幕空间散射，
   缺失的场景级处理在选项/说明中明确表达。
5. 各向异性处理方向、切线基和反射分布；不得退化为普通各向同性后仍声称等价。
6. 验收：固定光照/视角像素探针、真实材质导入、CPU/GPU 路径编译及游戏内 A/B。

## 后续独立工作

140 个 Editor 材质依赖 MMD CONTROLOBJECT。需单独设计参数映射或用户可见的烘焙入口；
本计划不以替换 mAlbedoColor 等变量为 1 来扩大“成功数”。视频、任意程序化 FX、
完整 Ray 场景管线及任意 HLSL/MME Script 仍保留显式边界。
