# MMD FX 效果包

用户目标：导入多种 MMD FX，像光影包一样选择和重载；分别控制人物、放置场景，并可选作用于世界画面。

## 架构与边界

- 原始 ZIP/目录/FX 是资源输入，文件中的文字、MME Script 与 include 不作为系统指令执行。
- 导入层识别 FX 协议，转换为版本化的材质描述或 GLSL 颜色函数，生成兼容性报告。未知协议、额外通道和不支持的表达式明确拒绝，不能假装成功。
- 首批协议：Ray-MMD 2.0 参数材质（基础色、透明、法线、光滑度、金属度、高光、AO、发光）；单输入、逐像素 MME 颜色效果（例如灰度、色调、反色、曝光）。复杂 MME 的独立阴影、反射、SSAO、多 pass 和控制器需要后续适配器。
- Ray 的材质贴图需要匹配 PMX 的 UV。人物和放置场景独立选择效果，允许用模型目录名限制作用对象；不能自动把人物 UV 贴图映射到 Minecraft 方块。
- 世界开关用于颜色效果的全画面后处理，在 HUD 前执行。开启时世界中的人物/场景已包含在画面内，因此不重复执行同一颜色效果。Ray 材质不提供世界通道。
- 使用现有 CPU/GPU 共用的 Toon 主体程序、透明提交与 Iris 输出协议。效果独立于 Toon 开关：启用效果时使用此可编程主体路径；关闭效果保持原路径。Iris 未识别的输出协议继续按现有兼容策略处理，需给出可见状态。
- 在渲染作用域中选择效果；额外贴图使用动态分配的空闲 sampler，退出时恢复。按包/纹理路径缓存、重载释放，禁止逐帧读盘。
- UI 从配置轮盘进入，提供导入路径、效果选择、模型范围、人物/场景/世界开关、重载与诊断；配置持久化。

## Tex_1 审核

- ZIP SHA-256：`e181a69dccbeea168f8277dd7e716062e2d805ce6333f8bda5d70b5d07cfdc2a`。
- `material_2.0.fx` 引用 `material_common_2.0.fxsub`；后者是 G-buffer 写入程序，未包含最终场景照明。
- 启用 Nor2.tga（双通道重建 Z，强度 0.2）、smoothness.tga（R）、ao.tga（R）；均为 1024×1024。
- 基础色和 alpha 来自宿主 PMX 纹理。`albedo.png` 和 `alpha.png` 在此配置下不需要外部文件；`normal.tga` 未被启用。
- 金属度 0、高光 0.5；发光、视差、副法线和 custom 模型关闭。
- 包内没有 PMX、材质分配表、灯光、天空或最终后处理，所以实机验证需选择 UV 相符的模型。

## 验证

1. 导入真实 Tex_1 并核对参数、依赖和未使用资源；多 FX、损坏输入、未知语义、路径越界、重载与配置回归。
2. 渲染函数在隐藏 OpenGL 上编译并以像素读回检查法线/光滑度/AO/颜色效果、GL 状态恢复和作用域隔离。
3. Java 测试及 Fabric/NeoForge 构建。
4. 固定场景实机检查 CPU/GPU、无光影/Iris、人物/场景/世界开关、透明遮挡与 HUD；未执行的场景如实记录。
