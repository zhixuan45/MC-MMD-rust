# 上游 1.20.1 完整物理链路移植

已获用户授权实施。主线基线 9333b83197ea443e78db517896e00fc24e15be06，上游 1.20.1 基线 5fe18f8fb741d25c31c89cdb22643609917446a0。

独立导入上游 Rust 刚体、关节、世界、配置与 C++ wrapper，C ABI 加 u120 前缀以隔离现有实现。默认模型只创建上游世界；旧实现保留用于显式 legacy-physics 参考构建，不参与默认模型。类型 2 默认映射为类型 1；upstream-native-mode2 仅供原样对照构建。

模型初始化、重置、运动学同步、惯性、步进、完整骨骼回写、非物理子骨骼传播恢复上游链路。当前渲染、动画播放、UI、平台与打包保持主线。适配层仅映射上游支持的配置和提供只读基本状态；不启用自动补体/裙摆补关节、旧头发限位/弹簧、尾巴增强、渲染预测或旧并行解算。

旧增强设置在本实验后端不生效，solver 保持上游默认 10；不伪造高级接触/关节诊断。只读高级诊断不可用会明确标记。保留原始 PMX/VMD；必要基础构建和关键接入测试通过后安装到当前 NeoForge 实例，备份现有模组。游戏视觉由用户验收。
